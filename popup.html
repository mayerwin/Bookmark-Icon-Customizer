?A webhook is a URL that triggers an action when called (e.g. opens a gate, toggles a light, posts a message). Clicking it normally navigates the browser and may try to download the response. ?A native javascript: bookmarklet runs inside the page you click it from. To attach a custom favicon, the bookmark has to be rewritten to a real URL — which means clicking it briefly navigates away and back.

Tick this if your bookmarklet reads or modifies the page (add a button, save selection, extract data, etc.). The code runs on your previous page after the round-trip. Asks once for permission to access all sites.

Leave it unticked for fire-and-forget bookmarklets that don't touch the page (open a URL, ping a server). No permission needed.

Limitation: the brief navigation uses Chrome's back-forward cache to restore your page with form values and JS state intact — works on most pages, but pages with a beforeunload handler (rich editors, dashboards) opt out of that cache, so clicking the bookmark there reloads the page and loses unsaved data. This happens on every click, not just the first. Keep DOM-modifying bookmarklets as raw javascript: URLs (no custom icon) if the target page falls into that bucket.
